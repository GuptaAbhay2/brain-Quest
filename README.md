# Brain Quest 🧠

A fully offline, no-login, dark-themed brain training game. Flutter + Provider + Hive. 40 levels, 4 mixed mini-games, local stats, no backend required.

## Getting Started

```bash
flutter pub get
flutter pub run build_runner build --delete-conflicting-outputs
flutter run
```

Re-run the `build_runner` command any time a Hive model (`LevelProgress`, `UserStats`) changes.

## Tech Stack

| Purpose | Package |
|---|---|
| State management | provider |
| Local database | hive, hive_flutter |
| Sound effects | audioplayers |
| Fonts | google_fonts (Baloo 2) |
| Code generation | build_runner, hive_generator |

## Architecture

Data flows in one direction, top to bottom:

```
Hive (device storage)
        |
DatabaseService              services/
        |
LevelProvider · StatsProvider    providers/
        |   (Consumer / context.read)
Screens                       screens/
        |   (built from)
Widgets                       widgets/
```

Separately, `LevelConfigGenerator` (in `utils/`) decides **which game type** appears on each of the 40 levels. It never touches Hive — it's recalculated from a fixed random seed every time the app starts, so the same level always gets the same game and difficulty.

`utils/` (colors, text styles, theme, constants, calculators) is imported by almost everything above — think of it as the foundation the rest sits on, not a "layer" in the flow.

## File Reference

### models/
Data shapes used across the app.

- **`game_type.dart`** — Enum for the 4 game types (`numberTap`, `wordBuilder`, `mathTrueFalse`, `imageNaming`) plus a `displayName` extension.
- **`level_progress.dart`** — Hive model. One record per level: `isUnlocked`, `isCompleted`, `starsEarned`, `bestTimeSeconds`, `wrongTaps`. This is the actual saved progress.
- **`user_stats.dart`** — Hive model. Global stats: `totalStars`, `currentStreak`, `lastPlayedDate`, `totalTimeSpentSeconds`, `totalScore`.
- **`game_configs.dart`** — Plain (non-Hive) classes describing what a level *is*: `NumberTapConfig`, `WordBuilderConfig`, `MathTrueFalseConfig`, `ImageNamingConfig`, and the umbrella `LevelConfig`. Never saved to disk — generated fresh each run.
- **`game_result.dart`** — Meant to carry a finished game's result. **Currently unused** — screens pass individual parameters to `ResultScreen` directly instead. Safe to delete or wire in later.
- **`level_progress.g.dart`, `user_stats.g.dart`** — Auto-generated Hive adapters. Never edit by hand; regenerated by `build_runner`.

### providers/
State that screens listen to.

- **`level_provider.dart`** — Holds all 40 `LevelProgress` records (loaded from Hive), exposes `currentLevelNumber` (first incomplete level) and `totalStarsEarned`. `completeLevel()` saves a finished attempt and unlocks the next level.
- **`stats_provider.dart`** — Holds `UserStats`. `recordGameSession()` updates streak (day-based), total time, and total score after every completed game.

### services/
Direct access to storage and hardware — providers call these, screens never do.

- **`database_service.dart`** — Singleton. Initializes Hive, opens the two boxes (`levelProgressBox`, `userStatsBox`), and seeds all 40 levels on first launch (only level 1 unlocked).
- **`audio_service.dart`** — Singleton. Plays `assets/sounds/tap.mp3` / `error.mp3` via `audioplayers`. Fails silently if the files aren't present.

### screens/
Full-page views.

- **`splash_screen.dart`** — Animated logo (scale + fade), auto-navigates to `MainNavigationScreen` after 2.5s.
- **`main_navigation_screen.dart`** — Bottom nav shell switching between Home and Analytics via `IndexedStack`.
- **`home_screen.dart`** — Welcome text, `GameSummaryCard`, and the scrollable level path (`LevelPathTile` list). Tapping a level asks `LevelConfigGenerator` which game it is, then pushes the matching game screen.
- **`analytics_screen.dart`** — Player stats dashboard: `PlayerRankCard`, `StreakCard`, `LevelMasteryCard`, and Time/Score `StatGridCard`s.
- **`result_screen.dart`** — Shared result screen used by all 4 games — animated stars, "New Best" badge, stats card, Home / Play Again / Next Level buttons.

### screens/games/
One file per game type. Each is a self-contained `StatefulWidget` that reads its config from `LevelConfigGenerator`, manages its own gameplay loop, plays tap/error sounds via `AudioService`, and on completion calls `LevelProvider.completeLevel()` + `StatsProvider.recordGameSession()` before navigating to `ResultScreen`.

- **`number_tap_game_screen.dart`** — Tap numbers 1→N in order. No timer; time itself is the score.
- **`word_builder_game_screen.dart`** — Spell a word from scrambled letter cards. Countdown timer; timeout shows a Replay dialog.
- **`math_true_false_game_screen.dart`** — 8 equations, True/False, per-question timer.
- **`image_naming_game_screen.dart`** — Spell the name of the pictured emoji/image. No timer; letters reveal progressively.

### widgets/
Reusable UI pieces built by screens.

- **`game_summary_card.dart`** — Home screen's top card (stars, level, streak, progress bar).
- **`level_path_tile.dart`** — One row in the level list — locked / current (big glowing "PLAY") / completed states, plus the connecting line and the Hero tag used in the game-screen transition.
- **`streak_card.dart`** — Analytics' circular fire-streak badge.
- **`player_rank_card.dart`** — Analytics' circular rank badge (Rookie → Legend).
- **`level_mastery_card.dart`** — Analytics' trophy-case card — circular completion ring + 3★/2★/1★ level counts.
- **`stat_grid_card.dart`** — Analytics' Time/Score cards (gradient background, faded corner icon).

### utils/
Shared helpers, imported wherever needed.

- **`constants.dart`** — Hive box names, `totalLevels` (40), `mathQuestionsPerLevel` (8).
- **`app_colors.dart` / `app_text_styles.dart` / `app_theme.dart`** — The entire dark theme: palette, text styles (Baloo 2), and the `ThemeData` applied in `main.dart`.
- **`encouraging_lines.dart`** — Random motivational line shown on Home.
- **`level_config_generator.dart`** — **The core game-design logic.** Assigns a game type to each of the 40 levels (10 of each, seeded shuffle), holds the word bank and image bank, and scales difficulty (number range, timers) by level number.
- **`star_calculator.dart`** — One method per game type, converting performance (time, wrong taps, accuracy) into a 1–3 star rating.
- **`app_page_route.dart`** — Custom fade + scale page transition, used instead of `MaterialPageRoute` everywhere.
- **`dialogs.dart`** — `showExitConfirmDialog()`, used by every game screen's AppBar back button.
- **`formatters.dart`** — `formatDuration()` — seconds → "Xh Ym" for Analytics.
- **`rank_system.dart`** — Defines the 6 rank tiers (Rookie, Explorer, Strategist, Pro, Master, Legend) by star thresholds.

### main.dart
Entry point: initializes Hive → wraps the app in `MultiProvider` (Level + Stats) → applies the dark theme → starts at `SplashScreen`.

## Game Types at a Glance

| Game | Timer | Star basis |
|---|---|---|
| Number Tap | None (self-challenge on time) | Time vs. par time, wrong taps |
| Word Builder | 60 / 30 / 20s by level | Time remaining, wrong taps |
| Math True/False | 15 / 10 / 20s per question | Accuracy over 8 questions |
| Image Naming | None | Time vs. par time, wrong taps |

## Making Common Changes

| I want to... | Go to... |
|---|---|
| Add new words / images | `level_config_generator.dart` |
| Change colors | `app_colors.dart` |
| Change fonts / text sizes | `app_text_styles.dart` |
| Make stars easier/harder to earn | `star_calculator.dart` |
| Change total level count | `constants.dart` (`totalLevels`) — then check the word/image bank in `level_config_generator.dart` doesn't run out |
| Add a 5th game type | `game_type.dart`, `game_configs.dart`, `level_config_generator.dart`, a new `screens/games/*.dart`, `star_calculator.dart`, and the switch in `home_screen.dart` |
| Replace sound effects | Swap the files in `assets/sounds/` — no code changes needed |

## Known Notes

- `game_result.dart` is not currently wired into the app — safe to ignore or delete.
- The exit-confirmation dialog only covers the AppBar back arrow, not Android's system back gesture/button.
- App icon is still the Flutter default — add `flutter_launcher_icons` before shipping.
- `assets/sounds/tap.mp3` and `error.mp3` need to be added manually (any short, free SFX works).
